# Property Tracker

Use this tracker for every property setup request handled by the Properties PR.

For the authoritative Teams property information index, use `working\property-information-ledger.md`.

## Status Terms

- `requested` - Wes named a property, but the template or required address details are not confirmed.
- `template pending` - a template recommendation has been made and this PR is waiting for Wes to confirm or replace it.
- `in setup` - the property folder/file package is being created or cleaned.
- `review needed` - files exist, but open cleanup, formula, source, or address-detail questions remain.
- `ready` - folders/files are created, cleanup is documented, and no setup blocker remains.
- `cancelled` - Wes cancelled or superseded the setup request.
