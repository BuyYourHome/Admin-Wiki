# Missing Context

## Home Assistant

- Mini manufacturer, model, CPU, memory, and storage.
- Host operating system and Home Assistant installation type.
- Home Assistant version and local URL or IP address.
- Current backup method, location, retention, and last successful backup.
- Critical integrations, automations, dashboards, and add-ons.
- Whether SSH, Terminal, Studio Code Server, or another administration add-on is installed.

## Remote Access Questions For Network Roadmap

- Should access be limited to the local network, available through VPN, or available through Home Assistant Cloud?
- Is Home Assistant Cloud/Nabu Casa already subscribed or acceptable as a paid service?
- Is Tailscale, WireGuard, another VPN, or an existing remote-access service already in use?
- Which computers and people need remote access?
- Is browser-only administration sufficient, or is SSH access also required?
- Should remote access continue working when WesStudio or OfficeAssist is off?
- Is inbound router port forwarding prohibited? The recommended default is yes.
- What availability, recovery, audit, and multifactor-authentication requirements apply?
