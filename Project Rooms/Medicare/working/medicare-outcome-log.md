# Medicare Outcome Logging Policy

Routine email intake, deduplication, comparison progress and handoff outcomes belong in approved non-Git operational state and authoritative Outlook/central message references. Keep personal prescription data and individualized reports outside Git. This file defines logging policy; it is not a transaction ledger.

Use minimal source reference, coverage year, status, evidence reference, unresolved question and verified outcome. Do not copy health details into shared messaging records. Git may hold explicitly approved non-sensitive workflow-development summaries only.
