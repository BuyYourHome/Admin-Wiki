# Missing Context

## Required Before Pilot Selection

- Microsoft 365 tenant licenses assigned to each relevant user.
- Windows edition and activation state for each candidate device.
- Whether each device is already registered or managed in Microsoft Entra or Intune.
- Local administrator and recovery-account plan.
- BitLocker status and recovery-key custody.
- Applications, scheduled tasks, connectors, shares, and automations tied to local user profiles.
- A genuinely noncritical Windows Pro pilot device.

## Required Before Messaging Transport Change

- Availability, recovery-time, and data-retention requirements.
- Required sender, receiver, and audit semantics.
- Whether a managed NAS/server or cloud-native queue is preferred.
- Migration, dual-run, rollback, and credential-rotation plan.
