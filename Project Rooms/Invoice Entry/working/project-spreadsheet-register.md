# Project Spreadsheet Register

Invoice Entry owns this lookup register until Wes explicitly transfers maintenance to a Project PR or another named workflow.

## Use Rules

- Use this register to identify the proposed active project-management workbook.
- Before every workbook edit, list or fetch the exact current file from the SharePoint `Property` drive root.
- Do not edit a workbook marked `DONT USE`, a similarly named historical workbook, or a workbook inside an individual property folder.
- Treat a filename change, duplicate candidate, missing workbook, or project-status conflict as a review item and update this register only after SharePoint verification.
- Record the verification date whenever the current SharePoint workbook list is refreshed.
